# Emo Party — мобильная игра «Найди пару» на Unity

12 карточек (6 пар) с оригинальными неоновыми иллюстрациями в стиле эмо 2000-х: эмо-котик, эмо-мишка, полароид, MP3-плеер, банка энергетика, череп с бантиком.
Игрок открывает по две карточки; совпали — остаются открытыми, нет — переворачиваются обратно.
Цель — открыть все пары за наименьшее число ходов и время.

## Содержимое

```
Assets/
  Scripts/
    CardData.cs     — ScriptableObject пары (название + лицевой спрайт)
    Card.cs         — карточка: клик, анимация переворота и «пульса» при совпадении
    GameManager.cs  — правила: тасование, проверка пар, ходы, таймер, рекорд (PlayerPrefs)
    UIManager.cs    — HUD (ходы, время) и окно победы
    BoardFitter.cs  — подгоняет сетку карт под любой экран (портрет 3×4, ландшафт 4×3)
  Art/Cards/
    fox.svg … bear.svg — эскизы старой темы, будут заменены на 6 карточек Emo Party
    back.svg — рубашка
```

## HTML-прототип

`prototype/index.html` — играбельный прототип в браузере (HTML + CSS + JS, один файл, без установки).
Повторяет правила Unity-версии: 6 пар, поле 3 × 4, вертикальная ориентация, ходы, таймер, рекорд, звёзды,
экраны «Заставка → Меню → Игра → Пауза / Победа» и «Настройки» с окном «Правила игры». Графика — простые неоновые SVG,
звуки синтезируются в браузере.

Запуск: откройте `prototype/index.html` двойным щелчком. Чтобы открыть с телефона в той же сети Wi-Fi:

```bash
python -m http.server 8000 --directory prototype
```

и зайдите на `http://<IP-компьютера>:8000`.

## Сборка сцены в Unity (Unity 6 LTS или 2022.3 LTS)

1. **Проект:** шаблон *2D (URP)* или *2D Core*. Платформа: File → Build Profiles → Android / iOS.
2. **Скрипты:** скопируйте папку `Assets/Scripts` в проект.
3. **Иллюстрации:** экспортируйте SVG в PNG 600×800 (Inkscape, Figma, Krita) и положите в
   `Assets/Art/Cards`. Texture Type = *Sprite (2D and UI)*. Можно и без экспорта — через пакет
   `com.unity.vectorgraphics`, но PNG проще и надёжнее на мобильных.
4. **Данные пар:** Assets → Create → Memory → Card Data, 6 штук (EmoCat, EmoBear, Polaroid, Mp3Player, EnergyCan, BowSkull),
   в каждой укажите `displayName` и `front`.
5. **Canvas:** UI → Canvas, Canvas Scaler = *Scale With Screen Size*, Reference 1080×1920, Match 0.5.
   Внутри:
   - `HUD` — два TextMeshPro: `MovesText`, `TimeText`;
   - `Board` — пустой RectTransform на большую часть экрана + `GridLayoutGroup` (spacing 24, padding 24)
     + `BoardFitter`;
   - `WinPanel` — полупрозрачная панель с `WinResultText`, `WinBestText`, значком `NewRecord`
     и кнопкой «Играть снова».
6. **Префаб карточки:** UI → Image, добавьте `Card`, сохраните в `Assets/Prefabs/Card.prefab`, удалите со сцены.
7. **GameManager:** пустой объект с `GameManager` и `AudioSource`; на Canvas — `UIManager`.
   Заполните поля в инспекторе (6 CardData, рубашка, префаб, Board, UIManager, звуки).
8. **Кнопка «Играть снова»:** OnClick → `GameManager.NewGame`.
9. Убедитесь, что на сцене есть `EventSystem` (создаётся вместе с Canvas) — без него клики не работают.

## Требования к иллюстрациям

- Формат карточки 3:4, исходник не меньше 600×800 (лучше 900×1200 для планшетов).
- Карточки должны различаться **силуэтом и основным цветом**, а не только деталями — на телефоне
  карта ~3 см.
- Единый стиль: неоновое свечение, светлый контур на тёмном фоне (#15101C), палитра — неон, преимущественно розовый (#FF2FB3, #FF7AD9, #9B5CFF, #2DE2E6, акцент #39FF88), одинаковая рамка.
- Фоны: меню — стена с граффити и объявлениями; игровое поле — пробковая доска объявлений с флаерами игр и концертов. Фон приглушён, чтобы карточки читались лучше.
- Рубашка не должна намекать на содержимое и должна быть одинаковой для всех карт.

## Идеи для развития (после 2 месяцев)

- Уровни сложности: 4 / 6 / 8 пар (код уже рассчитан на любое число `CardData`).

- Звёзды за результат (3★ — ≤ 9 ходов при 6 парах).

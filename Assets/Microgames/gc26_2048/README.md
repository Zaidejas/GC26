# gc26_2048

- Ветка: `game/gc26_2048`
- Неймспейс: `GC26._2048`
- Стартовая сцена: `Scenes/gc26_2048_Main.unity` (создать в Unity, повесить `Game2048`)
- Команда:

Как играть: сдвигайте предметы на поле 4×4 и объединяйте одинаковые — от травы до сыра
(трава → сено → корова → бидон молока → бутылка молока → сметана → творог → сыр).
Готовый сыр мышка уносит в норку. На партию 150 ходов.

Документы и прототип: `Docs~/gc26_2048_docs.zip` — GDD, план разработки, список задач и
браузерный прототип (`prototype/index.html`). Папки с `~` в конце Unity не импортирует.

# gc26_2048 — «Мышкин сыр» / Mousey's Cheese

- Ветка: `game/gc26_2048`
- Неймспейс: `GC26._2048`
- Стартовая сцена: `Scenes/gc26_2048_Main.unity` (один объект `gc26_2048` с компонентом `Game2048`)
- Команда:

Как играть: сдвигайте предметы на поле 4×4 и объединяйте одинаковые — от травы до сыра
(трава → сено → корова → бидон молока → бутылка молока → сметана → творог → сыр).
Готовый сыр мышка уносит в норку. На партию 150 ходов. Управление: свайпы, стрелки / WASD, Esc — меню.

## Устройство

| Папка | Что внутри |
| --- | --- |
| `Scripts/Core/` | Логика на чистом C#: `CheeseRules` (правила и очки), `Board` (поле, ход, слияние), `MoveResult` (события хода), `CheeseSession` (партия: счёт, ходы, норка), `IdleTimer` (секунды без ввода) |
| `Scripts/Save/` | `CheeseStorage`: рекорд, лучший предмет и звук в PlayerPrefs (`gc26_2048_*`), партия в `MicrogameSave.Folder(Id)/game.json` |
| `Scripts/View/` | Интерфейс собирается кодом: `CheeseUi` (помощники uGUI), `CheeseFrame` (кадр 9:16 в Safe Area), `BoardView` / `TileView` (поле, анимации на корутинах, пул плиток), `CheeseSwipe`, `CheeseAudio` (звуки-заглушки), `CheeseArt` (палитра и спрайты), `MousePeek` (мышка выглядывает при бездействии) |
| `Scripts/Game2048.cs` | Точка входа `IMicrogame`: экраны, ввод, сохранения, выход в оболочку |
| `Resources/gc26_2048/` | Спрайты 8 предметов и мышки (перенесены из HTML-прототипа), `mouse_face.png` — мордочка для «выглядывания», иконки кнопок |
| `Tools~/` | `make_mouse_face.py` рисует `mouse_face.png` по контурам мышки из прототипа (Python 3.8+, без библиотек). Unity эту папку не импортирует |
| `Editor/` | `CheeseSceneBuilder`: меню **GC26 → gc26_2048 → Build Main Scene** пересобирает сцену |
| `Tests/Editor/` | Unit-тесты логики (Window → General → Test Runner → EditMode) |
| `Docs~/` | `gc26_2048_docs.zip`: GDD, план, задачи, HTML-прототип. Unity эту папку не импортирует |

## Версия

Текущая версия — в `Scripts/Core/CheeseVersion.cs` (сейчас 0.0.1), видна на главном экране и в настройках.
При выпуске новой версии обновите её там, в поле `version` файла `microgame.json` и в `CHANGELOG.md`
(тест `CheeseVersionTests` проверяет, что всё совпадает).

## Языки

Английский (по умолчанию) и русский. Переключатель **Settings → Language / Настройки → Язык** доступен из главного
меню и из меню партии; выбор хранится в PlayerPrefs `gc26_2048_language`. Все тексты и названия предметов — в
`Scripts/Core/CheeseLocale.cs` (пакет Unity Localization не подключаем: пакеты меняет только организатор).
Новая строка = новый ключ в таблице с обоими переводами; тест `CheeseLocaleTests` проверяет, что переводы не пустые.

## Мышка при бездействии

Если игрок 10 секунд ничего не нажимает (клавиши, мышь, касания), из-за случайного края кадра выглядывает
мордочка мышки: выезжает, 2 секунды покачивает головой и прячется. Пока игрок бездействует, это повторяется каждые
10 секунд — видно, что игра не зависла. Любое нажатие сбрасывает отсчёт и сразу прячет мышку. Работает на всех
экранах, поверх окон, нажатия не перехватывает. Интервал — `IdleTimer.DefaultInterval`, длительность — `MousePeek.ShowSeconds`.

Всё, что игра создаёт, — дети объекта `gc26_2048` в её сцене; камера и EventSystem создаются,
только если сцена запущена отдельно (без оболочки). `Time.timeScale`, `DontDestroyOnLoad` и статическое
состояние не используются.

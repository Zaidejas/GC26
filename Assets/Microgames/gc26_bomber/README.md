# gc26_bomber — «Последний сигнал»

Top-down shooter / roguelite: ремонтный дрон пробивается через захваченную ИИ орбитальную станцию.
Главная механика — нагрев ядра вместо патронов.

- Ветка: `game/gc26_bomber`
- Неймспейс: `GC26.Bomber`
- Стартовая сцена: `Scenes/gc26_bomber_Main.unity` — один объект с компонентом `BomberGame`, всё остальное игра создаёт сама

## Платформа

Игра делается **под телефон, вертикально** (комнаты 17×30 клеток, вход снизу, двери сверху).
Джойстик движения — справа (правый большой палец), способности — слева, стрельба автоматическая.
В редакторе Unity мышь работает как палец, клавиатура тоже (WASD, Пробел, Shift, R, G, V, Esc).
Удобнее всего проверять через Window → General → Device Simulator.

## Структура кода

| Папка | Что |
|---|---|
| `Scripts/BomberGame.cs` | `IMicrogame`, точка входа и выход в меню |
| `Scripts/Core/` | `BomberContext` — корень сессии, все объекты игры — его дети |
| `Scripts/Domain/` | Чистый C#: `HeatModel` (нагрев), `HeatGovernor` (автоогонь), `BomberRng` (seed как в прототипе) |
| `Scripts/Data/` | Таблицы чисел из прототипа: враги, секторы, комнаты |
| `Scripts/Sim/` | `BomberWorld` — вся симуляция забега (порт прототипа), в пикселях прототипа |
| `Scripts/View/` | Пиксельный рендер: камера в RenderTexture 272×480, пулы спрайтов |
| `Scripts/Art/` | Пиксельная графика, рисуется кодом (те же спрайты, что в прототипе) |
| `Scripts/UI/` | Телефонный интерфейс: HUD, джойстик, кнопки, пауза |
| `Tests/EditMode/` | Тесты нагрева и симуляции: Window → General → Test Runner → EditMode |

## Что уже перенесено

- Сектор 1: генерация вертикальных комнат, укрытия, бочки, двери, маршрут сектора
- Враги: жук-сварщик, турель, разведчик, камикадзе, делитель (+ осколки), элиты
- Волны, зачистка, скрап, комбо, счёт
- Ядро: безопасная зона, Форсаж, перегрев; Сброс (сильнее на горячем ядре), ЭМИ, рывок, Разгон, заряженный выстрел
- Пауза, экран поражения / конца сектора, «В меню» → `exit(score)`

Дальше: награды и оружие, магазин, верстак, боссы, секторы 2–3, хаб и персонажи, «Тёмная станция».

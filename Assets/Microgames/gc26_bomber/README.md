# gc26_bomber — «Последний сигнал»

Top-down shooter / roguelite: ремонтный дрон пробивается через захваченную ИИ орбитальную станцию.
Главная механика — нагрев ядра вместо патронов.

- Ветка: `game/gc26_bomber`
- Неймспейс: `GC26.Bomber`
- Стартовая сцена: `Scenes/gc26_bomber_Main.unity` — один объект с компонентом `BomberGame`, всё остальное игра создаёт сама

## Платформа

Игра делается **под телефон, вертикально** (комнаты 17×30 клеток, вход снизу, двери сверху).
Джойстик движения — справа (правый большой палец), способности — слева, стрельба автоматическая.
В редакторе Unity мышь работает как палец, клавиатура тоже (WASD, Пробел, Shift, R, G, V, Esc).
Удобнее всего проверять через Window → General → Device Simulator.

## Структура кода

| Папка | Что |
|---|---|
| `Scripts/BomberGame.cs` | `IMicrogame`, точка входа и выход в меню |
| `Scripts/Core/` | `BomberContext` — корень сессии, все объекты игры — его дети |
| `Scripts/Domain/` | Чистый C#: `HeatModel` (нагрев), `HeatGovernor` (автоогонь), `BomberRng` (seed как в прототипе) |
| `Scripts/Data/` | Таблицы чисел из прототипа: враги, боссы, оружие, персонажи, улучшения, NPC, достижения |
| `Scripts/Sim/` | `BomberWorld` — вся симуляция забега (порт прототипа), в пикселях прототипа |
| `Scripts/View/` | Пиксельный рендер: камера в RenderTexture 272×480, пулы спрайтов |
| `Scripts/Art/` | Пиксельная графика, рисуется кодом (те же спрайты, что в прототипе) |
| `Scripts/UI/` | Телефонный интерфейс: HUD, джойстик, кнопки, пауза |
| `Tests/EditMode/` | Тесты нагрева и симуляции: Window → General → Test Runner → EditMode |

## Что уже перенесено

- Три сектора (Доки, Реакторный блок, Ядро ОРАКУЛА): вертикальные комнаты, укрытия, бочки, двери, маршрут сектора, переход «След. сектор»
- Враги всех секторов: жук-сварщик, турель, разведчик, камикадзе, делитель (+ осколки), щитоносец, снайпер, мортира, громила, ремонтник, фантом, лазерная турель
- Элиты со свойствами: быстрый, бронированный, взрывной, регенерация, щит
- 5 боссов с фазами: Грузчик МК-II, Матка роя, Плавильщик, Надзиратель, ОРАКУЛ (победа над ним — конец забега); полоска здоровья босса
- Опасности: горячие зоны (сектор 2), кислота и лава, мины, снаряды мортиры
- Волны, зачистка, скрап, комбо, счёт
- Ядро: безопасная зона, Форсаж, перегрев; Сброс (сильнее на горячем ядре), ЭМИ, рывок, Разгон
- Оружие (13 + 7 слияний) с альтернативными режимами, модули и наборы, компаньоны
- Сундук, алтарь, магазин, верстак (улучшения и слияние), награда за элиту и босса
- Обучение при первом запуске (8 шагов, кнопка «Пропустить», повтор — терминал «Тренировка» или пауза в хабе)
- Хаб: капсула персонажей, арсенал (открытие и стартовое оружие), мастерская (постоянные улучшения), достижения, спасённые NPC; дверь наверху — новый забег
- 8 дронов со своими характеристиками, особенностями и способностями: Искра, Шёпот, Бастион, Сапёр, Стриж, Кузня, Хронос, Пиявка; улучшения каждого дрона
- Данные за забег, спасение выживших (комната СПАСЕНИЕ) с бонусами, 15 достижений, открывающих оружие и персонажей
- Сохранение прогресса: `BomberMeta` в PlayerPrefs (`MicrogameSave.Key("gc26_bomber", "meta")`)
- «Тёмная станция»: карта темноты с источниками света, неоновые края укрытий, маяки, светящиеся глаза врагов (выключается в паузе)
- Пауза с размером кнопок, «Сдаться», экран поражения / победы с Данными, «В меню» → `exit(score)`
- Тактики на левой кнопке: Сброс, Купол, Блинк, Гравиграната, Крио-нова, Выброс ядра (терминал «Тактика» в хабе)
- Прицеливание перетаскиванием кнопки (Блинк, Гравиграната, динамит Сапёра), тап — умная цель
- Стрелки-указатели: к двери после зачистки, к сундуку и выжившему, к последним врагам за краем экрана
- Настройка управления: перетаскивание кнопок, джойстик слева/справа, видимость кнопок (пауза → «Настроить управление»)
- Журнал ошибок: ошибки с состоянием игры пишутся в `persistentDataPath/gc26_bomber/bug_log.txt`, в паузе — просмотр и «Скопировать отчёт»
- Меню «Разработка» (только редактор и development-сборка): сразу к боссу, зачистить комнату, неуязвимость, +Данные, открыть всё, FPS, сброс прогресса

Дальше: квесты NPC (и оружие-награды за них), уровни Перегрузки, Mk-улучшения оружия, мигающие стены сектора 3, звук.

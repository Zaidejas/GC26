- [ ] Окно победы появляется ровно один раз за игру
- [ ] Конец игры наступает, только когда нет хода ни в одну сторону
- [ ] Выход через «В меню» и новый запуск восстанавливают то же поле и счёт
- [ ] Рекорд сохраняется после перезапуска приложения
- [ ] Быстрое нажатие клавиш не пропускает ходы и не рассинхронизирует поле
- [ ] 60 FPS на телефоне средней мощности, ход ощущается мгновенным
- [ ] После возврата в оболочку не остаётся объектов, `Time.timeScale` равен 1

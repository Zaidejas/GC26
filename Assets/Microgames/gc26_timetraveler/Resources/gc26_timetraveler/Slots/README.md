# Art slots / Слоты для графики

Положи PNG сюда с **точным именем из таблицы**: игра сама заменит цветной прямоугольник на картинку.
Нет файла — остаётся прямоугольник, так что графику можно добавлять по одной штуке.

Put a PNG here with the **exact name from the table** and the game shows it instead of the coloured box.

- Масштаб: **16 px = 1 клетка**, экран 270×480 px.
- Pixel art: Unity сам ставит 16 PPU, Point filter, без сжатия (TimetravelerPixelArtImporter).
- «Растянуть» — картинка растягивается на размер объекта, рисуй ровно этот размер.
- «Плитка» — картинка повторяется (16×16 или 32×32), бесшовная.
- «Тонировать» — игра красит картинку в цвет мира (оранжевый PAST / голубой FUTURE): рисуй **светлыми нейтральными** цветами.

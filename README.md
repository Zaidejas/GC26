# Space Invaders (Unity, C#, Android, вертикально)

Классический Space Invaders: 5 волн, автострельба, кораблик идёт за пальцем, пауза, монетки, хилка, бункеры, рекорд. Вертикальный экран, референс 1284×2778.

## Управление
| Ввод | Действие |
|---|---|
| Палец (в редакторе: зажатая мышь) | кораблик идёт за пальцем по горизонтали |
| — | стрельба автоматическая |
| A / D, ← / → (для тестов) | движение |
| Кнопка II на экране, Esc или P | пауза |
| Нажатие на ячейку, клавиши 1, 2, 3 для тестов | способности |

## Как запустить (5 минут)

1. **Unity Hub → New project → Universal 2D** (или просто **2D**). Подойдёт Unity 6 или 2022.3 LTS.
2. Скопируй папки `Scripts` и `Editor` из этой папки `Assets` в папку `Assets` своего проекта.
3. Дождись, пока Unity скомпилирует скрипты (крутилка внизу справа).
4. В верхнем меню: **Tools → Space Invaders → Build Game**.
   - Если появится сообщение про TextMeshPro, нажми OK, дождись импорта и запусти **Build Game** ещё раз.
     (Или сделай вручную: Window → TextMeshPro → Import TMP Essential Resources.)
5. Откроется сцена **MainMenu**. Нажми **Play**.

Генератор сам создаёт:
- `Assets/Sprites`: пиксельные спрайты (игрок, 3 вида пришельцев по 2 кадра анимации, пули, монетка, взрыв, блок бункера);
- `Assets/Audio`: 8-битные звуки (выстрел, взрыв, монетка, попадание);
- `Assets/Prefabs`: Laser, Missile, Coin, Explosion, Invader_Squid / Crab / Octopus;
- `Assets/Waves`: Wave1, Wave2, Wave3, Wave4, Wave5;
- `Assets/Scenes`: MainMenu и Game, обе добавлены в Build Settings.

Дальше всё это можно менять руками: подставлять свои спрайты и звуки, двигать UI, крутить настройки в инспекторе.

Стиль игры: «фосфорный терминал», зелёный монохром. Графика игры лежит в `Assets/GameArt`, исходники SVG в папке `Art/svg`. Генератор берёт спрайты оттуда и подбирает масштаб, а без файла подставляет временный пиксельный спрайт.

CRT-эффект на весь экран задаётся шейдером `Assets/Shaders/CRT.shader`, а его сила настраивается в материале `Assets/Settings/CRT.mat`. Выключается галочкой у эффекта CRT в `Assets/Settings/Renderer2D.asset`.

## Билд игры
**File → Build Profiles** (в 2022: Build Settings) → **Windows** → **Build**. В списке сцен должны стоять MainMenu (0) и Game (1).

## Как устроена игра

```
MainMenu ──Play──► Game
                    ├─ GameManager   очки, жизни, монеты, конец игры, сохранение
                    │   └─ SoundManager
                    ├─ WaveManager ──► InvaderGrid ──► Invader ×N
                    ├─ Player (PlayerController)
                    ├─ Bunkers (BunkerBlock ×N)
                    └─ Canvas: UIManager + PauseMenu
```

| Скрипт | Что делает |
|---|---|
| `GameInput` | чтение клавиатуры; работает и со старым Input Manager, и с новым Input System |
| `PlayerController` | движение в пределах экрана, автострельба, мигание и неуязвимость после попадания |
| `Projectile` | пуля игрока (вверх) и ракета пришельца (вниз), обработка попаданий |
| `Invader` | анимация из 2 кадров, очки, взрыв, выпадение монетки |
| `InvaderGrid` | создаёт сетку по `WaveData`, двигает её змейкой, ускоряет, выбирает стрелка |
| `WaveData` | ScriptableObject с настройками волны |
| `WaveManager` | запускает 5 волн подряд, после последней объявляет победу |
| `Boss` | босс: движение, чередование атак, здоровье, ярость при половине здоровья |
| `LaserBeam` | лазер босса: линия-предупреждение, затем луч |
| `FallingMinion` | пришелец, вызванный боссом: падает и ранит игрока |
| `Coin` | падает вниз, игрок ловит её кораблём |
| `HealthPickup` | хилка: падает вниз, при подборе даёт +1 жизнь |
| `AbilityManager` | способности: цена в монетах, перезарядка, эффекты |
| `AbilityButton` | ячейка панели способностей: цена, КД, нажатие |
| `SafeArea` | держит HUD в безопасной зоне экрана |
| `BunkerBlock` | кирпичик бункера, можно восстановить |
| `Explosion` | вспышка, которая гаснет |
| `GameManager` | синглтон: очки, жизни, монеты, Game Over / Victory, рекорд и монеты в `PlayerPrefs` |
| `SoundManager` | звуковые эффекты |
| `UIManager` | HUD, надпись «WAVE N», экран конца игры |
| `PauseMenu` | пауза: `Time.timeScale = 0`, звук выключается |
| `MainMenu` | рекорд, все накопленные монеты, кнопки Play и Quit |
| `Editor/SpaceInvadersBuilder` | генератор ассетов и сцен (в билд игры не попадает) |

### Основные механики
- **Сетка пришельцев** двигается целиком. Когда крайний живой пришелец доходит до края экрана, сетка разворачивается и опускается на `stepDown`. Скорость равна `wave.speed × (1 + доля убитых × speedUpFactor)`, то есть к концу волны пришельцы до 1.75 раза быстрее.
- **Стрельба пришельцев**: раз в `missileInterval` (±40%) стреляет самый нижний живой пришелец случайной колонки.
- **Типы пришельцев**: верхний ряд Squid (30 очков), средние ряды Crab (20), нижние Octopus (10).
- **Монетки** выпадают с шансом `coinDropChance`. Монеты за забег прибавляются к общему счёту (`PlayerPrefs`), даже если выйти в меню из паузы.
- **Хилка**: банка Monster с шансом `healChance` падает сверху в случайный момент волны, не больше одной за волну. Даёт +1 жизнь, максимум 3. При полных жизнях просто исчезает.
- **Способности** покупаются нажатием на ячейку за монеты текущей игры. Щит: 5 монет, 1 секунда, перезарядка 10 с. Восстановление бункеров: 10 монет, перезарядка 20 с. Стрельба ×2: 15 монет, 5 секунд, перезарядка 20 с.
- **Бункеры** ломаются от ракет пришельцев и от самих пришельцев, когда те спускаются. Пули игрока проходят сквозь бункеры, иначе автострельба съела бы их за пару секунд.
- **Поражение**: кончились жизни (3) или пришельцы опустились до линии игрока.
- **Победа**: пройдены все 5 волн.
- **Связь между скриптами** через события C#: `GameManager.StatsChanged`, `GameManager.GameEnded`, `WaveManager.WaveStarted`, `InvaderGrid.Cleared` и `InvaderGrid.ReachedBottom`. UI ничего не знает о пришельцах, а пришельцы ничего не знают об UI.
- **Физика**: все коллайдеры триггеры. `Rigidbody2D (Kinematic)` есть только у пуль и монеток, этого достаточно, чтобы срабатывал `OnTriggerEnter2D`.

### Волны
| Волна | Сетка | Скорость | Стрельба | Шанс монеты |
|---|---|---|---|---|
| 1 | 4×6 | 1.5 | ~1.0 с | 20% |
| 2 | 5×6, из них 2–5 усиленных | 2.1 | ~0.73 с | 25% |
| 3 | 6×6 | 2.7 | ~0.5 с | 30% |
| 4 | 7×6, из них 2–5 усиленных | 2.7 | ~0.5 с | 30% |
| 5 | 7×6 | 2.7 | ~0.5 с | 35% |

Усиленные пришельцы выдерживают 2 попадания, дают 40 очков и с шансом 50% стреляют прицельно в игрока. Волны 3 и 5 это битвы с боссами, сетка там не появляется, поэтому её столбцы в таблице для них не используются.

| Босс | Здоровье | Очки | Скорость ракет | Атаки |
|---|---|---|---|---|
| Босс 1 (волна 3) | 100 | 500 | 9 | веер, прицельная очередь, рывок к игроку |
| Босс 2 (волна 5) | 200 | 1000 | 10 | стена с дырой, спираль, лазер с предупреждением, призыв пришельцев |

Боссы чередуют атаки случайно, без повтора подряд, и роняют монетку каждые 8 попаданий. Босс 2 при половине здоровья краснеет, атакует в 1.5 раза чаще и иногда запускает две атаки сразу.

Меняются в `Assets/Waves/Wave1..5` прямо в инспекторе. Чтобы добавить ещё одну волну: ПКМ → Create → Space Invaders → Wave, затем перетащи её в массив `Waves` у объекта WaveManager.

## Если что-то не так
- **Спрайты чёрные (проект на URP)**: Hierarchy → ПКМ → Light → Global Light 2D.
- **Ошибка про Input System**: Edit → Project Settings → Player → Active Input Handling → **Both**.
- **Кнопки не нажимаются**: в сцене должен быть объект EventSystem (генератор создаёт его сам).
- **Сбросить рекорд и монеты**: Edit → Clear All PlayerPrefs.
- **Перегенерировать всё**: снова Tools → Space Invaders → Build Game. Внимание: созданные генератором файлы перезапишутся.
